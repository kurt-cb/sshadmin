### First Time Setup
```bash
# 1. Run automated setup
./setup.sh

# 2. Create SSH CA keys
sudo ssh-keygen -t ed25519 -f /etc/ssh/ca_key -N ""

# 3. Start app
python3 sshadmin.py

# 4. Open browser
http://localhost:5000
```

### Common Tasks

**Add SSH User:**
- Hosts → Add Host
- Enter hostname and public key
- Save

**Add SSH User:**
- SSH Users → Add User  
- Enter username and public key
- Save

**Issue Certificate:**
- Certificates → Issue User/Host Cert
- Select user or host
- Set validity period
- Issue

### Security Notes
⚠️ Change SECRET_KEY in production!
⚠️ Secure CA keys with proper permissions!
⚠️ Use HTTPS in production!
⚠️ Enable database backups!

### Troubleshooting
- CA key errors: Check `/etc/ssh/ca_key*` exists
- Database errors: Delete `sshadmin.db` and reinit
- Port errors: `lsof -ti:5000 | xargs kill -9`
