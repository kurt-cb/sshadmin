What happens next

The server runs:

ssh-keygen -t <type> -b <bits> \
  -f {{ ca_key_path }} \
  -N "" \

On success you'll be redirected to the Server Config page where you can copy the public key. Hosts enrolled afterward will pick it up automatically via /api/ca-pubkey.
