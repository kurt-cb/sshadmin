Key Rotation

Rotate the host key when the private key may be compromised, on a regular schedule, or to replace a non-conformant key left by a web registration.

  1. Click Re-register Host below — this invalidates the current key and issues a new one-time enrollment token.
  2. Copy the one-liner shown on the next page and run it as root on {{ host.hostname }}. The script will:
    • Generate a fresh ecdsa-sha2-nistp521 key at /etc/ssh/ssh_host_sshadmin_ecdsa_key
    • Register the new public key with sshadmin
    • Receive and install the signed host certificate automatically
    • Reload sshd
  3. Done — the host presents its new CA-signed identity on the next connection.

Users' existing certificates are unaffected; only the host's identity changes. Clients verifying via @cert-authority will trust the new certificate without any known_hosts update.
