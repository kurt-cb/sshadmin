Welcome to SSH Certificate Admin

Complete this one-time setup before registering your administrator account.

Step 1 of 2 — Configure the Certificate Authority. The CA private key signs every user and host certificate this server issues. After this step you will be taken to the registration page to create your administrator account.
Keep the CA private key safe. It will be written to {{ ca_key_path }} with permissions 0600. Losing it forces re-issuing every certificate; leaking it compromises every host and user that trusts this CA.
