What this script does
  1. Generates a fresh ecdsa-sha2-nistp521 host key at /etc/ssh/ssh_host_sshadmin_ecdsa_key if one does not already exist.
  2. Downloads the sshadmin CA public key to /etc/ssh/sshadmin_ca.pub and writes /etc/ssh/sshd_config.d/99-sshadmin.conf with TrustedUserCAKeys + HostCertificate directives.
  3. POSTs the host public key + token to /api/enroll/host; the server validates the key type and marks the host enrolled.
  4. Reloads sshd so the new config takes effect.
