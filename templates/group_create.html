What is a CA Group?

A CA Group is a set of machines that share a Certificate Authority (CA) key for user authentication.

  • Users in the group can obtain a cert signed by the group CA.
  • Machines in the group trust that CA — so group members can log in.
  • Machines not in the group reject the cert outright.

Use groups to create isolated access zones: Accounting, DevOps, Contractors, etc. A machine can be in multiple groups, trusting multiple CAs simultaneously.
