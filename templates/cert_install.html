Manual install
{% if cert.cert_type == 'host' %}

If you'd rather not pipe to bash, do it by hand:

  1. Download the cert: 
    curl -fsSL "{{ install_url|replace('install/script', 'install/data') }}" -o /etc/ssh/ssh_host_ecdsa_key-cert.pub
sudo chmod 0644 /etc/ssh/ssh_host_ecdsa_key-cert.pub
  2. Add this line to /etc/ssh/sshd_config (or a drop-in under /etc/ssh/sshd_config.d/): 
    HostCertificate /etc/ssh/ssh_host_ecdsa_key-cert.pub
  3. Reload sshd: 
    sudo systemctl reload ssh   # or: sudo systemctl reload sshd
  4. Verify: 
    sudo sshd -T | grep -i hostcertificate
ssh-keygen -L -f /etc/ssh/ssh_host_ecdsa_key-cert.pub
{% else %}

If you'd rather not pipe to bash, do it by hand. The cert filename must match your private key's basename + -cert.pub:

  1. Download the cert next to your matching private key: 
    curl -fsSL "{{ install_url|replace('install/script', 'install/data') }}" \
  -o ~/.ssh/id_ecdsa-cert.pub   # use the basename of your key
chmod 0644 ~/.ssh/id_ecdsa-cert.pub
  2. (Optional) If you want to point ssh at a non-standard cert path, add to ~/.ssh/config: 
    Host my-server
    IdentityFile ~/.ssh/id_ecdsa
    CertificateFile ~/.ssh/id_ecdsa-cert.pub
  3. Verify the cert and its principals: 
    ssh-keygen -L -f ~/.ssh/id_ecdsa-cert.pub
