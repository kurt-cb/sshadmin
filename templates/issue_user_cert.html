About User Certificates

What are they?

SSH user certificates allow users to authenticate to any host that trusts the CA, without needing individual authorized_keys entries.

Benefits:

  • Centralized authentication
  • Time-limited access
  • Principals for role-based access
  • Audit trail

Usage:

ssh -i ~/.ssh/id_ed25519-cert.pub user@host
