About User Certificates

What are they?

SSH user certificates allow users to authenticate to any host that trusts the CA, without needing individual authorized_keys entries.

Benefits:

  • Centralized authentication
  • Time-limited access
  • Principals for role-based access
  • Audit trail

Critical Options:

source-address
Restrict certificate use to specific client IPs or CIDRs. The SSH server rejects auth if the client address doesn't match.
force-command
Lock the certificate to a single command. Useful for restricted shells, rsync-only access, etc.

Usage:

ssh -i ~/.ssh/id_ed25519-cert.pub user@host
