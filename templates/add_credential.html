About SSH User Keys

An SSH user key links your sshadmin account to a specific Unix login name on an enrolled host. Each credential can be issued a user certificate that lets you SSH into hosts that trust this server's CA.

The private key must live on the host you're associating it with. Copying private keys across machines is discouraged and will produce a warning.

Once added, issue a certificate via the Issue User Cert page.
