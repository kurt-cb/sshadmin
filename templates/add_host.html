How enrollment works
  1. Submit this form — sshadmin issues a one-time enrollment token for the host.
  2. Copy the generated bash script to a root shell on the target host.
  3. The script generates an ecdsa-sha2-nistp521 host key (only this type is accepted), installs the CA public key, and registers the host's public key with sshadmin via the REST API.
  4. Once enrolled, you can issue host certificates from sshadmin.
The token expires after 24 hours and cannot be reused.
